# NEXUS DATA COMMAND

엑셀·CSV 파일을 올리면 **브라우저 안에서** 데이터 구조를 자동 분석하고, 데이터에 맞는 관제 대시보드를 생성하는 웹서비스입니다.

> 업로드한 파일은 외부 서버로 전송되지 않습니다. 모든 계산은 사용자의 브라우저 메모리에서 이루어지며, 배포 시 CSP(`connect-src 'self'`)로 외부 전송을 브라우저 차원에서도 차단합니다.

## 주요 기능 (v0.1.0 — 구현 완료 범위)

| 구분 | 내용 |
| --- | --- |
| 화면 | 웰컴 → 데이터 소스 선택(업로드/데모) → 데이터 스캔 → 메인 관제실 → 차트 상세 분석 패널 → 설정 |
| 파일 | XLSX(여러 시트 선택, 수식 결과·서식 텍스트·오류 셀 처리), CSV(UTF-8/EUC-KR 자동 판별, 구분자 자동 감지) |
| 제한 | 20MB, 200,000행, 300열 / `.xls`·암호화 파일·확장자 위장 파일 거부 |
| 구조 분석 | 제목 행을 건너뛴 머리글 탐지, 숫자·문자·날짜 유형 검사, 역할(수치/범주/연도/시간/식별자/텍스트) 추론 |
| 품질 검사 | 결측치(0과 구분), 해석 오류(원본 행 번호 표시), 완전 중복 행, 빈 행, 결측률 경고 |
| 통계 | 합계·평균·중앙값·최댓값·최솟값, 범주별 집계, 연도별 증감률(전년 0·전년 없음 별도 처리), 상관계수, 분포 |
| 차트 | 규칙 기반 자동 추천(선·막대·도넛·누적 막대·산점도·히스토그램), 추천 사유와 집계 기준 표시 |
| 조작 | 필터(열 간 AND·값 간 OR), 차트 클릭 교차 필터, 상세 패널에서 차트 유형·기준 열·값 열·집계 방식·시간 단위 변경, 집계표 CSV 저장 |
| 인사이트 | **규칙 기반** 인사이트만 제공 (AI 분석은 미구현으로 명시) |
| 데모 | 공공기관 교육 운영 실적 **가상 데이터** (실제 업로드와 동일한 분석 엔진 사용, 화면에 가상 데이터 표시) |
| 연출 | GSAP 패널 등장·숫자 카운트업·스캔 진행·패널 슬라이드, 포인터 반응 글래스 패널, 애니메이션 수준 설정(OS 동작 줄이기 존중) |

## 빠른 시작

```bash
npm install
npm run dev        # http://localhost:5173
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm test` | 단위 테스트 (Vitest) |
| `npm run typecheck` | TypeScript 검사 |
| `npm run lint` | oxlint |
| `npm run build` | 타입 검사 + 프로덕션 빌드 (`dist/`) |
| `npm run preview` | 빌드 결과 미리보기 — `vercel.json`의 보안 헤더(CSP 포함)를 동일하게 적용 |
| `npm run samples` | `public/samples/` 샘플 파일 재생성 |

요구 사항: Node.js 22.18 이상 (개발 검증: Node 24.22 / npm 11.19)

## 샘플 데이터 (`public/samples/`)

- `demo-education.csv` — 데모 모드와 같은 가상 교육 실적 (151행, 결측 5건·중복 1건 포함)
- `demo-education.xlsx` — 위 데이터 + 제목 행 + 날짜 서식 셀 + `부서정보` 시트 (다중 시트 테스트용)
- `messy-sample.csv` — 오류 처리 확인용 (제목 행, 존재하지 않는 날짜, 숫자가 아닌 값, 0, 결측, 중복)

```

  engine/                분석 엔진 (UI와 독립, 단위 테스트 대상)
    parse.ts             파일 검증·CSV/XLSX 읽기·인코딩 판별
    infer.ts             결측·숫자·날짜 해석, 유형·역할 추론
    dataset.ts           머리글 탐지, 열 구성, 품질 검사
    aggregate.ts         필터, 그룹 집계, 증감률, 분포, 상관, 교차 집계
    recommend.ts         규칙 기반 차트 추천
    insights.ts          규칙 기반 인사이트
    demo.ts              가상 데모 데이터 생성 (시드 고정, 재현 가능)
  charts/                ECharts 모듈 등록, 차트 옵션·집계 기준 생성
  components/            공통 UI, 관제실 패널(KPI·차트 카드·필터·품질·인사이트·스키마)

```

## 데이터 정확성 원칙

- 모든 통계는 업로드한 데이터에서 직접 계산하며, 분석이 불가능하면 값을 만들지 않고 이유를 표시합니다.
- 빈 셀과 `-`, `N/A`, `NA`, `null`, `NaN`, `none`은 **결측**, `0`은 **값**입니다. 결측은 집계에서 제외되고 제외 건수가 표시됩니다.
- 수치가 모두 결측인 그룹의 값은 0이 아니라 "값 없음"입니다.
- 증감률 = (해당 연도 − 전년) ÷ |전년|. 전년 값이 0이거나 전년 데이터가 없으면 "산출 불가"로 표시합니다.
- 날짜는 실제 달력으로 검증합니다 (예: `2023-02-29`, `2024-02-30`은 오류).
- 열 유형은 결측을 제외한 값의 90% 이상이 해석될 때 확정합니다 (작은 표는 예외 1건까지 허용). 해석 실패 셀은 원본 행 번호와 함께 보고합니다.
- 비율·점수형 열(만족도, ~률, ~율, 점수, %)은 합계 대신 평균을 기본 집계로 사용합니다.
