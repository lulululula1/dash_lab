# 후속 기능 개발 로드맵

현재 버전(v0.1.0)에서 **구현하지 않은** 기능과 개선 과제입니다.

## 단기 (v0.2)

- **Web Worker 분석**: 큰 XLSX(수 MB 이상) 파싱 중 UI가 잠시 멈출 수 있음 → 파싱·분석을 Worker로 이동, 실제 진행률 표시
- **머리글 행 수동 지정**: 자동 탐지가 틀린 경우 사용자가 머리글 행·데이터 범위를 직접 선택
- **열 유형·역할 수동 변경**: 스키마 표에서 숫자↔문자, 범주↔텍스트 등 변경 후 재분석
- **날짜 필터 범위 선택**: 현재는 연 단위 선택 → 기간(시작~끝) 슬라이더
- **차트 추가·삭제·순서 변경**: 현재는 추천 차트 수정만 가능
- **차트 이미지 내보내기**(PNG/SVG), 대시보드 PDF 보고서
- **e2e 테스트**: Playwright로 업로드·필터·상세 패널 흐름 자동화

## 중기 (v0.3 ~ v0.5)

- **고급 편집**: 계산 열(예: 수료율 = 수료인원 ÷ 교육인원), 범주 그룹 묶기, 이상치 표시
- **대시보드 저장/불러오기**: 사용자가 명시적으로 저장할 때만 대시보드 구성(데이터 제외)을 JSON 파일로 내보내기·가져오기
- **다중 시트 결합**: 공통 키(예: 부서)로 시트 조인
- **월·분기 증감률**, 이동평균, 누적 합계
- **접근성 강화**: 차트 데이터 표 대체 보기, 키보드만으로 차트 항목 필터링

## 장기 — AI 분석 확장

- 서버 측 프록시(Vercel Functions 등)에서만 API 키 보관 — **프런트엔드에 키를 넣지 않음**
- 전송 전 사용자 동의, 전송 범위 선택(전체 데이터 대신 **집계 결과만** 전송하는 옵션 기본값)
- AI 결과는 "AI 분석" 표시로 규칙 기반 결과와 분리, 근거가 되는 집계 수치 함께 표시
- 자연어 질의 → 차트 사양(ChartSpec) 생성 → 기존 엔진으로 계산 (AI가 숫자를 직접 만들지 않도록)
- CSP `connect-src`에 프록시 도메인만 추가
